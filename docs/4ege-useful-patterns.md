# 4ЕГЭ: что берём в наш тренажёр

Проверено 2026-09-04 по публичному разделу 4ege.ru/online и страницам демоверсий 2027.

Используем только продуктовые принципы и публичную структуру экзамена, не копируем закрытые решения/теорию и не переносим тексты банка целиком.

Полезные паттерны для нашего продукта:
- ежедневный чек-лист подготовки;
- отдельная фиксация источника задания;
- «Показать решение» + «Теория» после попытки;
- каталог по экзамену/предмету/номеру;
- план на неделю, дневник подготовки, чек-лист по кодификатору;
- отдельные тренажёры навыков;
- для репетитора: проверка ДЗ, отчёт родителю, динамика по КИМ, журнал занятий;
- для иностранных языков: письменная и устная части, отдельные аудиоматериалы;
- для русского: отдельная проверка сочинения и изложения.

Нормативная структура у нас по-прежнему определяется проектами ФИПИ-2027. 4ЕГЭ используется как вторичная проверка и UX-референс.
