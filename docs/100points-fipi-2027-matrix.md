# 100points vs наш тренажёр — матрица развития 2027

Дата проверки: 2026-09-04.

## Источники

- ФИПИ: проекты КИМ ОГЭ/ЕГЭ 2027, спецификации, демоверсии и кодификаторы.
- 100points: публичный каталог и тренажёр используются только как UX/структурный референс. Задания не копируются в наш банк.

## Сравнение функций

| Функция | 100points | Наш тренажёр | Решение |
|---|---|---|---|
| Экзамен/предмет/номер/тема | Да | Да | Сохраняем |
| Пробник | Да | Да | Использовать один и тот же проверенный банк |
| Своя тренировка | Да | Частично | Добавить выбор номеров/тем/количества |
| Только нерешённые | Да | Нет | Добавить по истории ответов |
| Ошибки | Да | Да | Усилить статистикой по номеру/теме |
| Решить похожее | Да | Да | Подбирать по тому же task и другой смысловой модели |
| Показать решение | Да | Да | Добавить пошаговые объяснения там, где возможно |
| Фильтры по номеру/теме | Да | Да | Сохраняем |
| Источник задания | Иногда ФИПИ | Да | Обязательно показывать происхождение |
| Разные типы ответа | Да | v4: choice/text/number/multi/essay | Довести до всех предметов |
| Аудирование | Да для языков | Нет | Нужен отдельный audio-тип |
| Устная часть | Да для языков | Нет | Нужен speaking-тип |
| Карты/рисунки/таблицы | Да | Частично | Добавить media-поля в задания |
| Совместное занятие | Нет как ключевая фича | Есть концепт | Наша дифференциация, перевести на Worker |

## Правила банка после аудита

1. Нельзя считать разными моделями вопросы, где изменены только числа, порядок ответов или префикс «Вариант N».
2. Каждый номер КИМ должен иметь фиксированный taskType, answerType и проверяемое умение.
3. Официальная структура берётся из ФИПИ-2027. 100points используется только для проверки UX и разнообразия форматов.
4. Полный пробник, тренировка по номеру и тренировка по теме используют один банк.
5. Для каждого задания храним: id, task, topic, type, source, skill, model, explanation, media при необходимости.
6. Автогенерация разрешена только внутри уже проверенного прототипа и не увеличивает показатель «моделей».
7. Для развёрнутых ответов запрещена ложная автоматическая отметка «верно/неверно» без объективного ключа.

## Приоритет наполнения

### Уровень A — критично

- ОГЭ: русский, математика, история, обществознание, информатика.
- ЕГЭ: русский, профильная математика, история, обществознание, информатика.

### Уровень B

- Физика, химия, биология, география.

### Уровень C

- Литература и иностранные языки: нужны отдельные движки для развёрнутых ответов, аудирования и устной части.

## Проверенные публичные модели 100points, используемые как структурный benchmark

- ОГЭ русский: №9 — преобразование словосочетания; №10 — смысловой анализ текста; №11 — средства выразительности.
- ОГЭ история: №10 — работа с картой/схемой и историческим источником.
- ОГЭ информатика: №9 — анализ графа/схемы, подсчёт путей.
- ОГЭ география: №3 — географические закономерности, ранжирование объектов.
- ЕГЭ русский: №3 — стилистический анализ; №8 — синтаксические нормы; №9 — корни; №10 — приставки.
- ЕГЭ история: №4 — заполнение пропусков в таблице; №10 — историческая карта; №13 — атрибуция письменного источника.
- ЕГЭ обществознание: №7 — выбор позиций из списка на экономическом материале.

Это не означает, что 100points является нормативным источником. Нормативный источник — ФИПИ.
